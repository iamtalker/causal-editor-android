# 인과 편집기 안드로이드

삶의 상태와 행동, 결과를 노드와 화살표로 기록하는 편집기의 안드로이드 앱입니다. PC 편집기와 같은 화면을 쓰고, 파일 저장만 기기 저장소에서 처리합니다.

바이브 코딩은 주로 하나의 프로젝트를 발전시키는 데 초점이 있습니다. 그런데 사람의 삶은 원인과 결과로 이루어집니다. 예를 들어 "부자가 된다"라는 목적을 정해 두면, 이에 이르는 방법은 매우 많습니다. 인과 사슬은 트리가 아니라 여러 원인과 결과가 겹쳐 있는 연결망이므로, 시작 상태와 목표를 두고 노드와 화살표로 그려 봅니다.

## 설치

[릴리즈](https://github.com/iamtalker/causal-editor-android/releases)에서 최신 APK를 받아 설치합니다. 설치 전에 "출처를 알 수 없는 앱 설치"를 이 앱에 허용해야 합니다. 처음 실행하면 "모든 파일 관리" 권한을 요청합니다. 노드 파일을 저장하려면 허용해 주세요(Android 11 이상).

## 사용법

- 노드를 손가락으로 끌어 옮깁니다.
- 빈 곳을 한 손가락으로 밀어 화면을 옮기고, 두 손가락으로 확대·축소합니다.
- 빈 곳을 두 번 탭하면 노드가 추가됩니다.
- 노드를 한 번 탭하면 선택되고, 상자의 제목 자리를 누르면 제목을, 메모 자리를 누르면 메모를 바로 편집합니다.
- 상단 메뉴에서 정렬 모양(피라미드, 원형 등)과 포커스 모드를 쓸 수 있습니다. 포커스 모드에서 정렬하면 포커스로 보이는 노드만 배열됩니다.
- 노드 편집 칸의 "노드 md 파일 열기"로 노드 파일을 기기의 텍스트 앱에서 엽니다.

## 데이터

- 기본 폴더는 `내장 저장소/Documents/인과편집기`입니다. 설정에서 다른 폴더를 고를 수 있습니다.
- `노드파일/`의 Markdown 파일이 그래프의 원본입니다. 파일 하나가 노드 하나이고, 화살표는 파일 안의 링크로 적힙니다.
- `내부데이터/그래프.json`은 설정과 백업을 담는 보조 사본입니다.
- 여러 기기에서 쓰려면 이 폴더를 Syncthing 같은 도구로 동기화하면 됩니다. 앱은 열 때, '파일 다시 읽기'를 누를 때, 다시 보일 때 노드 파일을 읽어 반영합니다.

## 업데이트

- 앱을 열면 6시간마다 새 버전을 확인합니다. 새 버전이 있으면 화면 위 띠로 알립니다. 설정 창에서 자동 확인을 끌 수 있습니다.
- `업데이트`를 누르면 받아서 설치합니다. 설치 확인 화면에서 한 번 눌러야 설치됩니다. 설치 중에는 앱이 잠깐 꺼졌다 켜집니다.
- 새 버전으로 켜지면 '업데이트 완료' 알림이 뜹니다.

## 개인 데이터

노드 파일과 버전 기록에는 개인 기록이 들어갑니다. 이 앱의 데이터 폴더는 기기 안에만 두고, 공유하거나 GitHub에 올리지 마세요.
